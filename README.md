Repo for tools and scripts to support the Night Sky Symbology project https://nightskysymbology.wikidot.com

Setup:
1. Configure the identity.ini file
    [default@wikidot]
    user: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    key: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    site: nightskysymbology
2. Configure the config.py file with the appropriate directories

\src
Object needed to access the Wikidot API easily
Based on the API Whiffle, created by Soronlin, but updated and maintained for modern Python

\wiki
Tools for automatically making and processing wiki pages

\img
Tools for automatically making minor planet symbols
